## 4. 구현 단계에서 지킬 규칙 (프레임 승인 뒤)

`CLAUDE.md`의 경로 제거·교체 규칙을 그대로 적용한다. 이 영역은 같은 사고가 이미 네 번 난 곳이다(빈 EMR 복사, 타이핑한 판단 3칸 누락 등).
1. **입력 방향**: 위 표의 "입력" 행(3·5·6·7·8·9·10)은 새 칸에서도 **같은 저장 키**에 쓰고, **EMR 복사 출력까지 도달**해야 한다. 쓰기만 되고 읽히지 않는 칸을 남기지 않는다.
2. **출력 방향**: EMR 복사가 읽는 키(`herbalFinalAssessment`, `herbalClinicianObservations`, `herbalSafetyObservation`, `herbalFollowUpTargets`, `herbalReassessment`)는 이름도 형식도 바꾸지 않는다.
3. **표시 조건**: 값이 빈 문자열이 되는 순간 칸이 사라지지 않게 한다(행 4·6은 "값이 있을 때만"이라는 현재 규칙 그대로).
4. **테스트**: 옮긴 경로 1개당 소스 텍스트 단언 1개를 `tests/`에 추가한다.
5. 안전 사유 칩(행 3)과 안전이슈 문구(행 2)는 접히거나 스크롤 밖으로 밀리지 않는다.

## 5. PO 확인 요청 (프레임 승인 시)

- 재진·mixed·마무리 프레임을 다음 순서로 할지.

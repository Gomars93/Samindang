```
┌─────────────────────────────────────────────────────────────┐

│ 🟢 CLEAR   박OO · CH-0552 — 재검 예정 · 10:00     [재진]      │
```

라벨 + 클릭 시 신원 해소 플로우. 재진 행 부기는 안전 배지와 다른 시각 언어.
포트레이트(834): 동일 행 포맷, 시간만 2줄.

## 2. 공통 상단 크롬 (Clinical, variant 무관)

신원/주호소는 major section이 아니라 **얇은 페이지 헤더(chrome)**:
`김OO · CH-1023 · F/52 | 요통(LBP) · 3주째 | (재진 시) "지난 대비: …" (환자 보고)`
— "지난 대비"는 MicroFollowUp 응답 = PATIENT_FACT 스타일(인용부호+옅은 배경)로,
"다음"의 원장 PLAN 스타일(입력 필드)과 색·아이콘·형태 전부 분리 (절대 제약 4).

## 3. Variant 3개 요지

### V1 — 단일 세로 흐름 + 우측 앵커 레일
본문 한 줄기 스크롤(헤더→레인1→레인2→판단·처치→다음/종결), 우측 380px 레일은
탐색 보조(안전 pill·저장 상태·앵커)만 — 액션 복제 없음. 랜드스케이프에서 레일은
하단 고정 바로 대체. 클릭 합계 7. 약점: 판단 입력 중 안전 재확인에 스크롤 필요,
1024×768에서 헤더+레인1이 세로 잠식.

### V2 — 순차 단계형 (Stepper)
세그먼트 탭 4개(환자/확인/판단·처치/다음), 레인1은 **탭 밖 고정 배너 예외**.
클릭 합계 11~12 + 왕복 시 추가. 구조적 취약: "탭 시스템이지만 레인1만 예외"라는
특수 규칙을 유지보수 내내 지켜야 함 — profile 게이트 사고와 유사한 재발 패턴.

### V3 — 고정 좌측 컨텍스트 열 + 단일 작업 열 ★추천
좌측 고정 열(스크롤 무관 상시 가시): 신원·주호소·"지난 대비"(환자 보고 스타일)·
**레인1 안전 상태**·저장 상태. 우측 작업 열: 레인2 → 판단·처치 → 다음(발급·메시징
펼치기, 종결 EMR+완료).

```
Desktop 1440×900                          Tablet Landscape 1024×768
┌───────────┬─────────────────────┐      ┌──────────┬─────────────────┐

│ 김OO       │   □ 진찰소견 [4상태] │      │ CH-1023   │ ▼ 판단·처치      │
```

## 5. 추천: V3 — 근거

1. "레인1 항상 최상단·접힘 불가"를 취지대로 만족 — 판단 입력 중(안전 재확인이 가장
   필요한 순간)에도 시야 유지. V1/V2는 그 순간 스크롤/탭 전환 필요.
2. 클리닉 태블릿의 실제 사용(거치대 landscape 768px)에서 세로 손실 0.
3. 금지선을 규율이 아니라 **레이아웃 물리로 강제** — 레인1이 실수로 탭/스크롤 뒤로
   숨을 경로 자체가 없음 (profile 게이트류 사고 재발 방지).
4. 클릭 최선(7) + 시선 이동 최소.
5. operate.md 밀도·일관성/distill.md 카드-안-카드 금지에 부합 — 우측 열은 카드
   프레임 없는 연속 섹션.
단점: 1440+ 초광폭에서 좌측 열 여백 — 시각 문제일 뿐 개념·클릭·안전 무영향.

\# 핵심배오 INDEX  
  
| 배오 | 구조화된 목적 |  
|---|---|  
| \[\[당귀\]\] + \[\[황기\]\] | 혈허에 기허가 겹치거나 익기생혈 목적 |  
| \[\[백작약\]\] + \[\[감초\]\] | 완급지통·근긴장/경련성 통증 |  
| \[\[산조인\]\] + \[\[원지\]\] | 허성 안신 + 건망/심신교통 축 보완 |  
| \[\[향부자\]\] + \[\[당귀\]\] | 기체 + 혈허/조경 |  
| \[\[향부자\]\] + \[\[애엽\]\] | 기체 + 한응/냉성 조경 축 |  
| \[\[단삼\]\] + \[\[당귀\]\] | 활혈거어 + 보혈/조경의 역할 분담 |  
| \[\[우슬\]\] + \[\[숙지황\]\] | 간신/근골 보강 + 하행/통리 |  
| \[\[인삼\]\] + \[\[백출\]\] + \[\[감초\]\] | 비기허 보강 구조; 복령과 함께 사군자탕 틀에서 읽기 |  
| \[\[반하\]\] + \[\[진피\]\] | 담습 + 기체/위기상역; 이진탕 축 |  
| \[\[목향\]\] + \[\[진피\]\] | 장위 기체·창만의 행기조중 |  
| \[\[산사\]\] + \[\[신곡\]\] + \[\[맥아\]\] | 식적의 성격을 나눠 소도; 자동 삼합은 금지 |  
| \[\[산조인\]\] + \[\[백자인\]\] | 간담음/심혈 부족 불면 축 비교·보완 |  
| \[\[아교\]\] + \[\[애엽\]\] | 허성 출혈 + 온경지혈; 출혈 원인·임신 Safety Gate 선행 |  
| \[\[천궁\]\] + \[\[당귀\]\] | 활혈행기 + 보혈조경; 사물탕 역할 분담 |  
  
\> 배오표는 자동 처방표가 아니다. 각 약재의 \`왜 필요한지\`가 각각 설명되지 않으면 추가하지 않는다.

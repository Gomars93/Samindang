`MUST_EXCLUDE_EXTENSOR_MECHANISM_RUPTURE`

**Opus 결정 필요:**
`URGENT_REVIEW` vs `REVIEW_REQUIRED + expedited_referral_consider`.

---

## D. Locked knee / displaced meniscus

환자 후보:
- 무릎이 걸려서 **완전히 펴지지 않음**
- 단순 통증 때문에 펴기 힘든 것과 구분
- acute twisting injury 가능

clinician:
- true mechanical extension block
- effusion
- joint line tenderness
- McMurray/Thessaly only if tolerable and safe
- MRI/specialist referral context

AAOS 2024는 displaced/displacing acute meniscal tear, 특히 ROM 제한이 있는 경우 acute surgical intervention benefit 가능성을 언급.

제안:
`MUST_EXCLUDE_DISPLACED_MENISCAL_PATHOLOGY`

**Opus 결정 필요:**
true locked knee를 routine REVIEW로 둘지 `expedited_referral_consider`를 붙일지.

---

## E. DVT / VTE concern

환자 후보:
- 한쪽 종아리/다리 전체의 새로운 부종
- calf pain/tenderness
- 최근 수술/입원/장기간 움직이지 못함
- prior DVT/PE
- active cancer
- pregnancy/puerperium/hormonal context 등

clinician:
- other cause exclusion
- 2-level Wells when suspected
- ultrasound/D-dimer pathway는 medical evaluation

제안:
`MUST_EXCLUDE_DVT`

**Opus 결정 필요:**
- tablet에서는 symptom trigger만 받고 Wells는 clinician-side로 둘지
- high-risk combination에 즉시 `URGENT_REVIEW`를 줄지
- 모든 DVT concern을 `REVIEW_REQUIRED + dvt_assessment_required`로 둘지

---

## F. Systemic inflammatory / malignancy / referred pathology

환자 후보:
- cancer history / unexplained weight loss
- multiple hot/swollen joints
- prolonged morning stiffness / inflammatory pattern
- systemic illness
- hip/lumbar symptoms dominating knee complaint

원칙:
- night pain 단독 = malignancy red flag로 사용하지 않음
- knee OA/meniscus/PFP label로 non-knee pathology를 가리지 않음

제안:
`MUST_EXCLUDE_SYSTEMIC_OR_REFERRED_PATHOLOGY`

# 5. Key Objective Discriminators — clinician-side

## A. Weight-bearing / function
- ability to walk
- chair rise
- stairs
- squat
- target function reproduction

## B. ROM
- active flexion/extension
- passive flexion/extension
- extension deficit
- true mechanical block vs pain-limited ROM

## C. Effusion
- visible/ballotable/sweep test as appropriate
- rapid traumatic effusion increases suspicion for significant intra-articular injury
- effusion alone does not identify structure

## D. Extensor mechanism
- straight-leg raise
- active extension / extensor lag
- patellar/quadriceps tendon palpation

## E. Ligament
- Lachman
- pivot shift only when appropriate
- valgus/varus stress
- posterior drawer/sag when indicated

## F. Meniscus
- joint-line tenderness
- McMurray
- Thessaly only when safe/tolerable
- **true locking/ROM block supersedes provocative-test cascade**

## G. Patellofemoral
- squat / step-down / stair reproduction
- patellar mobility/apprehension when indicated
- hip/knee strength and movement strategy

# 6. Meniscus Calibration

AAOS 2024는 acute isolated meniscal pathology에만 적용한다.

### 허용
- acute twist + joint-line pain + mechanical symptoms + concordant exam
  → `ACUTE_MENISCAL_INJURY = CONSIDER/HIGHER_SUPPORT`
- true extension block / displaced-tear concern
  → specialist urgency consideration

### 금지
- chronic OA 환자의 MRI meniscal tear를 통증 원인으로 자동 확정
- McMurray 하나 양성 = tear confirmed
- Thessaly 양성 = surgery indication
- acute isolated-meniscus CPG를 chronic degenerative tear에 그대로 적용

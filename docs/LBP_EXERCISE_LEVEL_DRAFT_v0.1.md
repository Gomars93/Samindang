# 요통 재활운동 레벨 배정 초안 v0.1 (원장 검토용)

> **이 문서의 성격**: Fable이 **제안**한 초안이다. 임상 판단이 아니다.
> 배정 근거는 (a) 발표된 TBC 3단계의 정의와 (b) 각 운동에 이미 적혀 있는
> `시작 기준`뿐이며, **Fable이 임상 규칙을 창작하지 않았다.**
> **모든 행은 원장(Product Owner) 승인 전까지 확정이 아니다.**

## 참고한 표준

**TBC (Treatment-Based Classification, Physical Therapy 2016 / 2017)**

| 단계 | 원문 정의 요약 | 이 문서 표기 |
|---|---|---|
| Symptom modulation | 최근 발생·재발했고 증상이 두드러져 **허리 움직임 자체가 제한**된 환자. 통증 유발원과 그 여파를 조절 | **1단계 · 증상 조절** |
| Movement control | **중등도 통증·장애**. 관절·연부조직 유연성과 신경근 조절이 주 제한 요인. 움직임의 질 개선 | **2단계 · 움직임 조절** |
| Function optimization | **낮은 통증·장애**, 활동 복귀 단계. 기능 수행 능력 향상 | **3단계 · 기능 최적화** |

**ODI (Oswestry Disability Index)** — 0~20% 최소 / 21~40% 중등도 / 41~60% 중증 /
61~80% 심각 / 81~100% 침상. 한국어판 검증됨.

> **미확인 사항(정직하게 기록)**: TBC 3단계와 ODI 점수를 잇는 **공식 컷오프는
> 논문에 없다.** TBC는 "moderate pain and disability status" 같은 서술로만
> 기술한다. **경계선은 원장이 정해야 하며 Fable이 지정하지 않는다.**

## B. 원장이 정해야 하는 것 3가지

### B-1. ODI 경계선 2개
```
ODI  0 ~ [    ]%  →  3단계 (기능 최적화)
ODI [    ] ~ [    ]%  →  2단계 (움직임 조절)
ODI [    ]% 이상  →  1단계 (증상 조절)
```
> 참고: ODI 자체 구분은 0-20 최소 / 21-40 중등도 / 41-60 중증이다.
> 그대로 쓸지, 다르게 쓸지는 원장 판단.

### B-2. 확신도 ◐·○ 7개 행
3(고양이낙타) · 9(배에 힘주기) · 12(브릿지) · 13(다리 옆으로 들기) ·
14(앉았다 일어서기) · 17(신경 왕복) · 18·19(점진 노출)

**●인 13개 행은 넘어가셔도 됩니다.**

### B-3. 단계를 올리는 기준
재진에서 무엇을 보고 다음 단계로 올리는가?
각 운동에 이미 `진행(progressionKo)` 항목이 있으나, 그건 **한 운동 안에서의
진행**이고 **단계 간 이동 기준은 아직 없다.**

## C. 별도 안건 — "안전 금기"와 "난이도"의 분리

현재 준비조건 15개는 **안전과 난이도가 섞여 있다.** 레벨 체계는 "무엇을
줄까"를 정하지 "주면 안 되는 것"을 막지 않으므로, 진짜 안전 금기만 남겨야 한다.

**Fable의 관찰(제안이지 판단이 아님)**: 15개 중 대부분은
`엎드리기 가능 / 네발기기 가능 / 앉기 견딤` 같은 **자세 수행 가능 여부**다.
못 하면 그 운동이 안 되는 것이지 **위험한 것은 아니다.**

**그리고 중요한 발견**: 진짜 안전 내용은 **이미 각 운동의 `중단 기준
(stopReviewKo)`에 들어 있다.**

> 예: `새로운 또는 진행하는 신경증상` / `하지 증상이 더 아래로 퍼지는 반응이 반복`
> / `보행 후 회복되지 않는 현저한 악화`

→ **즉 안전은 이미 운동마다 붙어 있고, 준비조건 게이트는 상당 부분 중복이다.**

**원장 판단 필요**: 15개 중 "이건 확인 안 하면 위험하다"는 것이 몇 개인가?
Fable의 짐작으로는 `안전한 보행 가능` 정도이나, **이건 원장이 정할 일이다.**

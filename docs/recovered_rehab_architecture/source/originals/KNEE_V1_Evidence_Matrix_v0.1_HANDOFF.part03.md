+ functional instability
```

의 조합으로 본다.

특수검사:
- Lachman
- pivot shift
- anterior drawer
- lever sign

모두 완벽한 rule-in/rule-out이 아니며 검사 상황/시기에 따라 정확도가 달라진다.

### 금지
- Lachman 하나로 ACL 확정
- giving-way 하나로 ACL 확정
- MRI 없이/있어도 clinician context 없이 수술 적응 자동결정

# 8. OA Calibration

NICE NG226의 clinical OA pattern을 활용하되 자동진단은 하지 않는다.

`KNEE_OA_PATTERN = HIGHER_SUPPORT` 후보:
- age >=45
- activity-related knee pain
- morning stiffness none or <=30 min
- compatible gradual/recurrent course
- no major alternative safety/trauma pattern

### 단,
- age만으로 OA 확정 금지
- X-ray grade와 pain/function을 동일시하지 않음
- severe pain = severe radiographic OA라고 추정하지 않음
- atypical features → alternative/additional diagnosis 검토

# 9. PFP / Tendon Calibration

## PFP
2024 best-practice:
- education
- knee-targeted ± hip-targeted exercise
- patient-specific adjuncts

태블릿에서는:
- anterior pain location
- stairs/squat/running/prolonged sitting behavior
정도만 수집.

## Patellar tendon
- localized load-related tendon pain
- jumping/running/decline-type load response
- rupture safety 먼저

### 금지
- “무릎 앞 통증 = PFP”
- “점프할 때 아픔 = patellar tendinopathy”
- 영상상 tendinosis = 증상 원인 확정

# 10. Imaging Principle

## OA
NICE:
- typical clinical OA는 routine imaging 불필요
- follow-up에도 routine imaging으로 non-surgical management를 guide하지 않음

## Acute trauma/fracture concern
ACR:
- focal tenderness / effusion / inability weight-bear 등에서 radiograph 고려
- gross deformity/high-risk는 decision rule보다 clinical judgment 우선

## Acute isolated meniscus
AAOS 2024:
- MRI is preferred imaging when imaging is needed to diagnose acute meniscal tear

## PFP/PT
- routine imaging으로 초기 conservative care를 결정하지 않음
- PT imaging added value limited

Tablet이 영상검사를 자동 처방하지 않는다.

# 11. Exercise / Rehabilitation Architecture

KNEE도 동일:

**Clinical OS 후보 2–3개 → 원장 승인/삭제/교체 → 최종 1–2개**

입력:
- target function
- irritability
- ROM
- effusion
- strength
- load response
- instability
- movement control
- patient goal
- safety

Domain:
- activity / aerobic
- mobility
- quadriceps strength
- hamstring/calf/hip strength
- neuromuscular / balance
- sit-to-stand / squat / stair tolerance
- gait/load progression
- PF-specific graded loading
- tendon load progression
- ligament return-to-function
- graded exposure

### 금지
- OA = quad exercise 1개 고정
- PFP = VMO isolation hard-code
- meniscus = 무조건 회전 금지
- ACL = diagnosis만으로 동일 rehab
- tendon = 무조건 rest
- safety/locking/extensor rupture concern에서 routine progression

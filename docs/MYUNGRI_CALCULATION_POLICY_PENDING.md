# 만세력/명리 계산 정책 — 미확정 사항 (원장 승인 대기)

이 문서는 `src/saju/` 계산 엔진이 **아직 결정하지 않고 코드에서 플래그만 남긴** 명리학적 판단들을 추적합니다.
날짜/간지 변환 자체는 결정론적 라이브러리(`manseryeok`) 연산이지만, 아래 항목들은 **역학적으로 논쟁이 있는
규칙**이며 임상 도구에 어떻게 반영할지는 원장 박경남의 확정이 필요합니다.

엔진은 이 문서의 항목들에 대해 **보수적 기본값을 계산하되, 대안도 함께 계산해 결과에 남기고, 무엇이
불확정 상태인지 `flags`/`policy.pending_approval`로 명시**합니다. 코드가 조용히 하나를 골라 숨기는 일은 없습니다.

임상 사용 전, 아래 각 항목에 대해 원장 확인/승인이 필요합니다. 승인 전까지 기본값은 변경하지 않습니다.

---

## 1. 야자시/조자시 (23:00~00:59 출생의 일주·시주 기준)

- **질문**: 23:00~00:59 사이에 태어난 환자의 일주(日柱)·시주(時柱)를 어느 날짜 기준으로 볼 것인가?
- **현재 코드 기본값**: `'midnight'` — 자정(00:00)에 날짜가 바뀐다고 보고, 일주·시주 모두 **당일** 일간(日干) 기준으로 계산.
- **대안**:
  - `'jasi'` — 자시(23:00)부터 이미 다음날이 시작된 것으로 본다. 일주·시주 모두 **다음날** 일간 기준.
  - `'splitJasi'` — 일주는 당일 그대로 유지하되, 시주의 천간만 다음날 일간을 기준으로 계산 (전통 야자시/조자시 절충설).
- **영향 범위**: 23:00~00:59 출생자에 한정. 이 구간이 아니면 세 방식 모두 결과가 같음. 세 결과 모두
  `SajuResult.alternatives.dayBoundary`에 저장되며, 기본값(`midnight`) 결과만 `pillars`에 노출됨.
- **확정 필요 사유**: 유파(流派)마다 채택하는 기준이 다르고, 일주가 바뀌면 일간 기준 십신 해석 전체가 달라짐. 계산 라이브러리는 세 방식을 모두 지원하나 선택은 명리학적 판단.
- **원장 승인**: ☐ 미승인

## 2. 진태양시(眞太陽時) 보정

- **질문**: 환자가 말한 시계 시각(표준시)을 실제 태양 남중 기준 시각으로 보정할 것인가?
- **현재 코드 기본값**: `'not_applied'` — 보정 없음. 환자가 말한 시각을 그대로 사용 (라이브러리 호출 시 `trueSolarTime` 옵션을 아예 넘기지 않음).
- **대안**: 적용 시 아래 세 요소를 함께 고려해야 함.
  - 출생지 경도 보정 (예: 서울 126.978°E — 표준시 자오선 135°E와의 차이만큼 시각 이동)
  - 균시차(equation of time) 보정
  - 과거 표준시/서머타임(일광절약시간) 보정 — 한국은 1954~1961년, 1987~1988년 등 표준시가 변경된 이력이 있음
- **영향 범위**: 절기 경계(입춘 등) 근처 출생자는 보정 적용 여부에 따라 **월주·연주까지 바뀔 수 있음**. 시주는 대부분의 출생자에게 영향을 줄 수 있음(2시진 경계 근처는 특히).
  엔진은 절기 경계로부터 1일 이내인 경우 `flags.near_solar_term = true`로 표시하고 `policy.pending_approval`에 `'true_solar_time'`을 추가함.
- **확정 필요 사유**: 보정 적용 여부와 방식(경도 기준점, 서머타임 반영 여부)이 유파마다 다르고, 절기 경계 출생자는 결과가 뒤바뀔 수 있어 임상적으로 민감함.
- **원장 승인**: ☐ 미승인

## 3. 출생시각 세부 규칙 (12시진 경계, 분 단위 처리)

- **질문**: 시진 경계에 걸친 출생(예: "새벽 5시쯤"이 묘시 시작 직전/직후 애매한 경우), 분 단위 반올림을 어떻게 다룰 것인가?
- **현재 코드 기본값**: 문진에서는 환자가 12시진 중 하나를 직접 선택(`timeBranch`)하도록 하며, 엔진은 그 선택을 그대로 신뢰함.
  분·시 단위 원본 시각 입력은 받지 않음 — 시진 선택 자체가 입력의 정밀도 한계이자 UI 단순화 정책.
  엔진 내부적으로는 이미 선택된 시진 **안에서** 결정론적 대표 시각(구간 중간값, 자시만 예외)을 사용해 라이브러리에 전달함 — 이는 시진을 재판정하는 것이 아니라 이미 정해진 시진 내부의 한 점을 명명하는 것뿐임.
- **대안**: 분 단위 정밀 시각을 직접 입력받아 시진을 자동 판정 (환자가 정확한 시각을 아는 경우에만 유효, UI/문진 설계 변경 필요).
- **영향 범위**: 시진 선택 UI/문진 설계와 `timeConfidence`('exact' | 'approximate') 필드의 실제 활용 방식.
- **확정 필요 사유**: 문진에서 시진 대신 분 단위 시각을 받을지, 그리고 애매한 경계 케이스를 환자에게 어떻게 되물을지는 임상 워크플로 설계에 해당.
- **원장 승인**: ☐ 미승인

## 4. 시주(時柱)의 임상적 비중 — 시간 미상 환자 처리

- **질문**: 시주를 임상 판단에 얼마나 비중 있게 반영할 것인가? 출생 시각을 모르는 환자는 어떻게 다룰 것인가?
- **현재 코드 기본값**: 시간 미상(`timeBranch`가 `'unknown'` 또는 `null`)이면 시주를 **계산하지 않음** —
  `SajuResult.status = 'partial'`, `pillars.hour = null`, `flags.hour_unknown = true`. 연주·월주·일주는 그대로 계산됨.
  대표 시각을 추정해 시주를 채워 넣는 일은 하지 않음.
- **대안**:
  - 통계적으로 흔한 출생 시간대를 대표값으로 사용 (비추천 — 추측을 결과처럼 감추게 됨)
  - 시주 없이 연·월·일주만으로도 문진 목적에 충분하다고 정책적으로 규정하고 UI에서 시주 관련 항목을 아예 숨김
- **영향 범위**: 시간 미상 환자 비율이 높을 경우, 시주 기반 해석을 요구하는 임상 항목의 커버리지에 영향.
- **확정 필요 사유**: 시주를 얼마나 신뢰해 임상 판단에 쓸지는 명리학적·임상적 판단이며, 엔진은 계산 가능 여부만 판정함.
- **원장 승인**: ☐ 미승인

## 2. 공통 상단 크롬 (Clinical, variant 무관)

신원/주호소는 major section이 아니라 **얇은 페이지 헤더(chrome)**:
`김OO · CH-1023 · F/52 | 요통(LBP) · 3주째 | (재진 시) "지난 대비: …" (환자 보고)`
— "지난 대비"는 MicroFollowUp 응답 = PATIENT_FACT 스타일(인용부호+옅은 배경)로,
"다음"의 원장 PLAN 스타일(입력 필드)과 색·아이콘·형태 전부 분리 (절대 제약 4).

## 8. Addendum (Phase 6 Gate 반영 — B-4·M-7)

### 8.1 V3 좌/우 재분배 (B-4)
좌측 고정 열 = **고정 높이 요약만** (자체 스크롤 금지): 신원 3줄(~60px) + 주호소·
기간(~40) + "지난 대비"(~24) + 안전 결론 요약(상태 칩+🔒+부위 N 명단+근거 보기,
~56) + 저장 상태(~20) ≈ **200px** — 1024×768에서도 여유. 834 portrait 스티키는
2줄 압축 ≈ 96px.
레인1 **전문**(배너 원문·계산불가·부위 칩·잠금 문구·권장 검사 목록)은 **우측 작업
열 최상단, 접힘 컨트롤 없이** 배치.

**최악 케이스 치수 (1024×768, NECK+SHOULDER 동시 URGENT + 권장 검사 15개):**
우측 열 폭 ≈ 700px 기준 — 배너(~120px) + 부위 전문 2블록(각 제목 24 + 칩 2줄 56 +
잠금 2문단 72 + 검사 목록 15×24=360 → 1블록 최대 ~512, 검사 6개 블록 ~296) 합계
~930~1,050px. **우측 열은 페이지 스크롤로 자연 수용** (비접힘 보장이 요구사항이지
1-viewport 수용이 아님). 좌측 요약은 어떤 케이스에도 200px 고정 — "판단 입력 중
안전 재확인 비용 0"은 좌측 요약이 담당하고, 전문 재열람은 근거 보기 앵커 1클릭.
834×1112: 스티키 요약 96px + 본문 최상단 전문 — 동일 원리.

### 8.1a 좌측 요약 절단 규칙 (delta C-2 — 상한 보장)

200px(portrait 96px)은 "고정"이 아니라 **결정론적 절단 규칙으로 보장되는 상한**이다:
- 관련 부위 명단: **최대 2개 + `외 N`** — 초과분은 `근거 보기` 앵커(우측 전문
  비접힘)가 책임. 절단은 은닉이 아니다: 전문이 우측 열 최상단에 항상 펼쳐져 있다.
- `계산불가`는 별도 줄이 아니라 **상태 칩 접미**(`계산불가 — 허리 외 1`).
- 인증 만료 인라인 액션(§2.9)은 저장 상태 줄을 **대체**한다(증설 아님).
- §5 지표 "좌측 열 자체 스크롤 0"의 검증 기준 = 위 절단 규칙 구현 여부 + 최악
  fixture(부위 3+계산불가+auth 만료)에서 상한 유지.

\# 핵심주의 INDEX  
  
\#\# 우선 확인  
\- \*\*감초:\*\* 장기/고용량, 고혈압, 부종, 저K, 관련 약물 병용 → \[\[감초\]\]  
\- \*\*단삼:\*\* 항응고/항혈소판, 수술 전후, 출혈 위험 → \[\[단삼\]\]  
\- \*\*우슬:\*\* 임신 가능성, 출혈/항응고 축 → \[\[우슬\]\]  
\- \*\*애엽:\*\* 혈열·음허화왕 출혈과 구분, 산부인과 red flag → \[\[애엽\]\]  
\- \*\*원지:\*\* 위염·궤양·오심/위장 자극 → \[\[원지\]\]  
\- \*\*인삼:\*\* 불면·심계·혈압/흥분성 반응 추적 → \[\[인삼\]\]  
\- \*\*반하:\*\* 포제품 확인; 생반하 독성/자극성과 열담·음허조해 구분 → \[\[반하\]\]  
\- \*\*맥아:\*\* 수유 중에는 회유 의도 여부를 먼저 확인 → \[\[맥아\]\]  
\- \*\*아교:\*\* 비위허약·담습/구토·설사 및 실열/어혈성 출혈과 구분 → \[\[아교\]\]  
\- \*\*산사:\*\* 위산과다·비위허약에서 과용 주의 → \[\[산사\]\]  
\- \*\*백자인:\*\* 연변/설사·장활에서 윤장성 고려 → \[\[백자인\]\]  
\- \*\*천궁/현호색:\*\* 출혈 위험·항혈전약 병용은 현대 자료 별도 검토 → \[\[천궁\]\], \[\[현호색\]\]  
  
\#\# 절대 규칙  
이 파일은 \*\*현대 안전성 DB의 대체물이 아니다.\*\* 실제 처방 시 약물상호작용, 임신/수유, 간·신기능, 출혈위험은 최신 현대 자료와 별도 대조한다.

질문 위에 소단계가 표시된다: `갱년기 문진 · 2/5 주요 증상` (`Question.section`, 순수 presentation).

## 4. 안전 규칙 (PO 2026-09-27, `src/spec/midlifeLogic.ts`)

**URGENT_REVIEW** — 한의원 진료를 멈추고 즉시 대응
- 공통 안전문항 `SAFETY_01` 양성(흉통·심한 호흡곤란·신경학적 증상·의식소실·멈추지 않는 출혈 등) — 이미 모든 환자에게 먼저 물으므로 다시 묻지 않고 합친다
- MID_08 대량 출혈 + 어지러움/쓰러질 것 같음 (= 대량출혈 + 순환불안정 의심)
- MID_08 구체적인 자살·자해 생각 또는 계획
- 임신 가능성(`WOMEN_SAFETY_01` 임신 중/가능성) + 출혈 — "심한 복통·실신"은 `SAFETY_01`이 이미 URGENT로 잡는다

**PRIORITY_EVALUATION** — 한의원 진료는 가능, 외부평가 지연 금지
- 폐경 후 출혈(12개월 무월경 응답자의 모든 출혈 포함) · 지속/반복 비정상 출혈 · 성교 후 출혈 · 지속적 복부팽만/골반통/종괴감 · 설명되지 않는 체중감소/발열 · 지속 또는 운동 시 악화하는 심계항진
- **임신 여부 "모름" + 출혈 → PRIORITY로 표시(URGENT 아님).** Claude 추가 — **PO 승인(2026-09-28)**. 이 표시가 뜨면 진료 때 임신 여부를 직접 확인한다.

**INCOMPLETE** — 안전 응답이 없거나 형식 오류, 또는 출혈이 있는데 임신 가능성 미응답. "안전"으로 읽지 않는다. URGENT 근거가 하나라도 있으면 URGENT가 이긴다.

태블릿 즉시 인터럽트(직원 확인 화면): **URGENT만** — `MID_08` 제출 직후, 임신+출혈 조합은 `WOMEN_SAFETY_01` 제출 직후.
PRIORITY는 인터럽트하지 않는다(부위 팩 REVIEW와 같음).

> ⚠ 운영 전제: 태블릿이 자살·자해 문항에서 직원 확인 화면을 띄우면 **직원이 즉시 응대하는 절차**가 있어야 한다. 화면만 있고 응대 절차가 없으면 이 문항은 넣지 않는 것보다 위험하다. → **PO SOP v0.1 확정·반영(2026-09-28, 아래 최소판을 대체)**: 양성이면 태블릿 문진을 **중단**하고 지금까지의 응답을 제출,
> 환자에게는 "직원이 바로 도와드릴게요" 대기 화면(계속·뒤로 없음), 원장 화면에는 URGENT + "MID_08에서 중단됨" + SOP 4줄
> (`QUESTIONNAIRE_HALT_TRIGGERS`, `PatientCompleteScreen` halted, `MIDLIFE_SELF_HARM_PROTOCOL`). 이전 최소판(참고):
> 태블릿 직원 확인 화면에는 이유를 드러내지 않는 직원 한 줄("환자분 곁에 머물며 조용한 곳으로 모시고, 원장님께 바로 알려주세요"),
> 원장 화면 갱년기 안전 칸에는 3줄 — ① 혼자 두지 않고 조용한 곳으로, 원장 즉시 호출 ② 원장이 다음 순서로 먼저 보고 계획·수단·시점을 묻는다
> ③ 임박 위험 119 / 그 외 109·정신건강의학과 안내, 진료기록에 남김. 문구 원본은 `midlifeLogic.ts`(`MIDLIFE_SELF_HARM_PROTOCOL`, `MIDLIFE_STAFF_NOTE`).
